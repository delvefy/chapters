Welcome to Chapters

Chapters stores your book as plain .txt files in a GitHub repository — one file per chapter. To connect it, you need a fine-grained Personal Access Token:

  1. Open github.com/settings/tokens → “Fine-grained tokens” → Generate new token.
  2. Under Repository access, select only the repo that will hold your book.
  3. Under Permissions → Repository permissions, set Contents to Read and write. Nothing else is needed.

🔒 The token is stored only in this browser's local storage, on this device. It is never sent anywhere except directly to api.github.com. Anyone with access to this device profile could read it — use a token scoped to a single repo, and revoke it on GitHub if the device is lost.
